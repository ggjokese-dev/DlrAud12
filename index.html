Roblox 안전 백과

펫 거래 · Robux · 아이템 · 게임(체험) · 채팅 · 계정 · 신고 · 해킹 의심까지 한곳에서 확인하는 개인용 홈페이지입니다.

모르는 내용은 그냥 넘어가지 말고 카드를 눌러 자세히 읽어보세요.

🛑 1. 멈추기

상대가 “지금 당장”, “오늘만”, “안 하면 취소”라고 해도 먼저 멈춥니다.

🔎 2. 확인하기

무엇을 주는지, 무엇을 받는지, 공식 Roblox 기능인지 확인합니다.

📝 3. 기록하기

사용자, 체험, 채팅, 시간, 거래 화면 등 필요한 정보를 기록합니다. 비밀번호·인증 코드는 기록하거나 공유하지 않습니다.

🚨 4. 신고하기

문제가 되는 대상이 사용자·체험·채팅·아이템 중 무엇인지 구분해 신고합니다.

1. 사기 종류를 아주 많이 알아보기

비슷해 보이는 사기도 방법이 다릅니다. 상황을 눌러 확인하세요.

💰 펫 먼저 보내기

“먼저 펫을 보내면 내가 나중에 다른 펫을 줄게.” → 먼저 보내지 않습니다. 공식 기능 밖의 약속은 보호되지 않을 수 있습니다.

🎁 무료 희귀 펫

“공짜로 드림. 링크 눌러.” → 무료 보상을 이유로 로그인·개인정보를 요구하면 멈춥니다.

🪙 무료 Robux

“Robux 생성기”, “무료 Robux 코드” 등을 믿지 않습니다. Roblox는 Robux 생성기가 없다고 안내합니다.

🔗 가짜 Roblox 로그인

Roblox처럼 꾸민 사이트에 아이디·비밀번호를 입력하게 하는 방식입니다. 공식 Roblox 로그인 화면이 아니면 입력하지 않습니다.

🍪 쿠키 달라고 하기

브라우저 쿠키를 보내 달라는 요청은 거절합니다. 계정 접근에 악용될 수 있습니다.

🔐 인증번호 달라고 하기

“인증번호 하나만 알려줘”라고 해도 주지 않습니다. 이메일 OTP·2단계 인증 코드·백업 코드는 비밀입니다.

👥 계정 빌리기

“내가 대신 키워줄게”, “거래 대신 해줄게”라며 계정을 요구하면 거절합니다.

💵 현금 거래

Roblox 공식 기능 밖에서 실제 돈과 아이템·계정 등을 교환하는 거래는 위험합니다. 계정이나 그룹 등을 대가로 하는 거래도 피합니다.

⏰ 급하게 결정시키기

“30초 안에”, “지금 아니면 끝” 같은 압박은 판단을 어렵게 만듭니다. 급하면 더 멈춥니다.

🧑‍💻 외부 메신저 이동

외부 메신저로 이동한 뒤 링크·돈·계정 정보를 요구하는 경우가 있습니다. 모르는 사람이 외부로 보내면 특히 조심합니다.

🎭 가짜 관리자

“나는 Roblox 직원”, “관리자라서 확인해야 한다”면서 비밀번호나 인증 코드를 요구해도 알려주지 않습니다.

🏆 가짜 이벤트

“당첨됐다”, “선물 받았다”며 외부 링크 로그인이나 개인정보 입력을 요구하면 먼저 공식 출처인지 확인합니다.

🧪 가짜 테스트

“거래 테스트니까 펫을 먼저 보내라”는 말도 안전한 이유가 되지 않습니다.

🔄 나중에 돌려주기

“잠깐 빌리고 다시 줄게”도 빌려주는 순간 위험해질 수 있습니다.

📸 화면 공유 사기

화면 공유를 켜고 로그인 화면·인증 코드·개인정보를 보여 달라고 하면 중단합니다.

📥 수상한 프로그램

“이 프로그램을 설치하면 펫을 복사할 수 있다” 같은 말을 믿고 출처 불명의 프로그램을 설치하지 않습니다.

2. 게임 종류별로 생각하기

게임 이름이 달라도 안전 원칙은 같습니다. 아래는 자주 생길 수 있는 상황 종류별 연습입니다.

🐶 펫을 교환하는 게임

펫의 이름과 희귀도만 보고 판단하지 말고 실제 거래창에서 무엇을 주고받는지 확인합니다. “먼저 보내기”는 피합니다.

⚔️ 아이템 거래 게임

무기·스킨·한정 아이템 등을 외부 사이트에서 교환하자는 제안을 조심합니다.

🔪 한정 아이템 게임

희귀하다는 이유로 급하게 거래하지 않습니다. 공식 거래 기능과 실제 거래 조건을 확인합니다.

🏠 집·장식 게임

집 꾸미기 아이템을 준다며 계정이나 외부 링크를 요구하면 멈춥니다.

🎟️ 게임패스 판매

게임패스·개발자 제품 등을 이용한 판매는 Roblox 공식 판매 기능의 범위를 확인하고, 상대가 별도의 외부 약속을 붙이지 않았는지 봅니다.

🎨 UGC·아바타 아이템

아이템 자체가 규정을 위반했다고 생각되면 아이템 신고 기능을 사용할 수 있습니다.

🎮 체험(게임) 자체가 문제

특정 사용자가 아니라 체험 콘텐츠 자체가 문제라면 체험 신고를 선택합니다.

💬 채팅으로 생긴 문제

문제가 되는 메시지와 사용자를 확인하고 채팅 신고 절차를 이용합니다.

3. 거래를 할 때 10단계 확인

1
STOP — 상대가 재촉하면 멈춥니다.
2
WHO — 누구와 거래하는지 확인합니다.
3
WHAT — 무엇을 주고받는지 확인합니다.
4
WHERE — Roblox 공식 기능 안인지 확인합니다.
5
FIRST — 내가 먼저 보내야 한다면 다시 생각합니다.
6
ACCOUNT — 계정 정보를 요구하면 즉시 중단합니다.
7
LINK — 수상한 외부 링크를 열지 않습니다.
8
SCREEN — 화면 공유로 비밀 정보를 보여주지 않습니다.
9
SAVE — 문제 상황은 필요한 범위에서 기록합니다.
10
REPORT — 문제가 있으면 알맞은 대상을 신고합니다.

5. 계정 보안 — 이것은 비밀

정보공유기억할 말
비밀번호❌친구도 알려주지 않습니다.
이메일 OTP❌로그인 확인 코드입니다.

개인정보⚠️주소·전화번호 등은 함부로 공유하지 않습니다.
화면 공유⚠️비밀 정보가 화면에 보이지 않게 합니다.

🔒 2단계 인증

계정 설정의 보안 메뉴에서 2단계 인증을 설정할 수 있습니다. 인증 코드는 다른 사람에게 공유하면 안 됩니다.

📧 이메일 연결

계정에 이메일을 추가하면 비밀번호 재설정과 보안 기능 사용에 도움이 됩니다.

🔑 강한 비밀번호

다른 사이트와 같은 비밀번호를 반복해서 사용하지 않는 것이 좋습니다.

📱 로그인 승인

내가 로그인하지 않았는데 승인 요청이 오면 승인하지 말고 계정을 확인합니다.

6. Robux 관련 안전 확인

🪙 “Robux 생성기”

Roblox는 Robux 생성기가 없다고 안내합니다. 이런 사이트·영상·체험은 사기 가능성을 의심하고 신고하세요.

🎁 “무료 Robux 코드”

무료 Robux를 준다는 링크나 코드를 믿고 로그인하지 않습니다.

💳 구매

구매할 때는 공식 Roblox 구매 화면을 사용하고 필요한 경우 보호자에게 도움을 요청합니다.

💸 Robux 보내기

Robux 전송은 취소가 안 될 수 있으므로 상대와 금액을 확인한 뒤 진행합니다. Roblox의 현재 전송 한도와 자격 조건도 확인하세요.

7. 신고 접수 방법 — 종류별로

🎮 게임 안에서 사용자 신고

왼쪽 위 메뉴 → 신고(Report) 방패 아이콘 → 사용자 선택 → 위반 사유 선택 → 설명 → 제출.

🎮 게임(체험) 자체 신고

같은 신고 메뉴에서 체험을 선택하고 문제되는 콘텐츠와 사유를 적어 제출합니다.

💬 채팅 신고

채팅창 오른쪽 위 점 세 개 → 악용 신고/부적절한 내용 신고 → 신고 대상 선택 → 안내에 따라 제출합니다.

👤 사용자 프로필 신고

사용자 프로필 → 채팅 옆 점 세 개 → 신고 → 사유 → 설명 → 제출.

🎨 아이템 신고

아이템 정보 상자 오른쪽 위 점 세 개 → 아이템 신고 → 양식 작성 → 제출.

🚫 차단

사용자 프로필의 점 세 개 메뉴에서 차단할 수 있습니다. 신고와 차단은 목적이 다르므로 필요한 경우 각각 확인합니다.

📝 신고 문장 만들기

누가 + 어디서 + 무엇을 했는지 순서로 적어보세요.

8. 이미 문제가 생겼다면?

😰 펫을 이미 보냈어요

추가 거래를 멈춥니다. 상황을 기록하고 관련 사용자를 신고합니다. 공식 기능 밖에서 한 거래는 Roblox가 아이템이나 Robux를 돌려줄 수 없을 수 있습니다.

🔑 비밀번호를 알려줬어요

가능하면 즉시 비밀번호를 변경하고 계정 보안 설정을 확인합니다. 2단계 인증도 확인합니다.

📧 인증번호를 알려줬어요

계정 보안을 바로 확인합니다. 내가 하지 않은 로그인 승인 요청이 있으면 승인하지 않습니다.

🦠 이상한 프로그램을 설치했어요

추가로 실행하거나 로그인 정보를 입력하지 말고, 기기 보안 점검을 진행합니다. 비밀번호를 입력했다면 계정 보안도 함께 확인합니다.

🌐 가짜 사이트에 로그인했어요

Roblox 공식 계정의 비밀번호를 가능한 한 빨리 변경하고 2단계 인증 등 보안 설정을 확인합니다.

📱 로그인할 수 없어요

Roblox의 공식 지원·계정 복구 절차를 이용합니다. 다른 사람이 알려주는 복구 링크를 무조건 믿지 말고 공식 지원 페이지인지 확인합니다.

13. “이 사람 사기꾼인가? 해킹범인가? 테러범인가?” 판단하기

⚠️ 사람의 정체를 혼자 단정하지 마세요. “의심되는 행동”과 “확인된 사실”을 나누어 생각합니다. 실제 신고에서는 상대방을 사기꾼·해커·테러범이라고 단정하기보다 무슨 행동을 했는지 적는 것이 안전합니다.

🟢 정상일 가능성이 있는 행동

공식 Roblox 기능 안에서 정상적으로 게임을 하고, 비밀번호·인증 코드를 요구하지 않으며, 외부 링크를 강요하지 않는 경우입니다. 그래도 이상한 행동이 생기면 다시 확인합니다.

🟡 의심 단계

계속 외부 링크로 보내기, 무료 아이템을 미끼로 로그인 요구, 비밀번호·쿠키·인증 코드 요구, 반복적인 도배 등이 있으면 행동을 기록하고 거래를 멈춥니다. 이것만으로 상대의 신원을 확정할 수는 없습니다.

🔴 명확한 신고 사유가 될 수 있는 행동

실제로 규정 위반으로 보이는 메시지·콘텐츠·사기 시도·괴롭힘 등이 있다면 해당 사용자나 콘텐츠를 신고합니다. 신고에는 확인한 사실을 적습니다.

🚨 해킹이 의심될 때

내 계정에서 내가 하지 않은 로그인·비밀번호 변경·아이템 이동·Robux 변화 등이 보이면 계정 보안부터 확인합니다. 상대를 추적하거나 공격하지 말고 공식 계정 복구 절차를 이용합니다.

🚨 “테러”라는 말을 들었을 때

게임에서 누군가 “테러”라는 말을 했다고 해서 실제 테러범이라고 판단하지 않습니다. 실제 위협처럼 보이는 구체적인 행동이나 콘텐츠가 있다면 직접 대응하지 말고 Roblox 신고 기능과 필요한 경우 보호자·관련 기관에 도움을 요청합니다.

🧠 가장 중요한 구분

“이상하다” = 의심 / “내 계정에서 실제로 이상한 변화가 확인됐다” = 계정 보안 문제 가능성 / “규정 위반 행동을 확인했다” = 해당 행동을 신고입니다.

14. 도배(스팸)·반복 메시지 대처

💬 같은 말을 계속 보내요

반복 메시지를 따라 답장하지 말고 필요한 경우 채팅 신고 절차를 이용합니다. 증거가 필요하다면 상황을 기록합니다.

🔗 같은 링크를 계속 보내요

링크를 열지 않습니다. 반복해서 보내는 계정은 차단과 신고를 검토합니다.

📣 여러 명이 동시에 도배해요

한 명씩 싸우지 말고, 필요한 경우 각각의 사용자와 메시지를 기록한 뒤 신고합니다.

🔇 채팅을 보기 싫어요

게임의 채팅·개인정보·커뮤니케이션 설정을 확인합니다. 메뉴 이름은 기기와 업데이트에 따라 다를 수 있습니다.

🚫 도배 + 욕설/괴롭힘

단순히 메시지가 많다는 것과 괴롭힘·위협 등 다른 위반 행동은 구분합니다. 신고할 때 실제로 있었던 행동을 적습니다.

16. Roblox에 접속하고 게임에 들어가는 방법

📱 휴대폰·태블릿

  1. 공식 Roblox 앱을 설치합니다.
  2. Roblox 계정으로 로그인합니다.
  3. 하단의 체험/Games 메뉴로 이동합니다.
  4. 검색창에 게임 이름을 입력합니다.
  5. 원하는 게임을 선택합니다.
  6. Play(재생) 버튼을 누릅니다.

Roblox 공식 모바일 안내도 체험 메뉴에서 검색한 뒤 체험 페이지의 Play 버튼을 누르는 방식으로 설명합니다. citeturn1search3

💻 컴퓨터

  1. 공식 Roblox 웹사이트에 접속합니다.
  2. 로그인합니다.
  3. 체험을 검색합니다.
  4. 게임 페이지에서 Play를 누릅니다.
  5. 필요한 Roblox 프로그램이 실행되도록 안내를 따릅니다.

⚠️ 검색 결과의 광고나 이상한 사이트가 아니라 공식 Roblox 주소인지 확인합니다.

🔐 접속할 때 주의

  • 친구가 보낸 이상한 로그인 링크 사용하지 않기
  • 무료 Robux 때문에 다른 사이트 로그인하지 않기
  • 비밀번호를 채팅으로 보내지 않기
  • 다른 사람이 알려준 프로그램 설치하지 않기

17. Roblox 게임 개발 시작하기

💻 Roblox Studio는 Windows와 Mac에서 사용할 수 있는 무료 제작 프로그램입니다. 공식 문서에는 Studio 설치, 첫 경험 만들기, 기본 UI 학습 과정이 제공됩니다. citeturn1search0turn1search5
